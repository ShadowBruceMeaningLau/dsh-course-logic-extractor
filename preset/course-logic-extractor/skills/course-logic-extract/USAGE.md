# 课程逻辑提取器 · 使用指南

> 本 agent 的使命：给定一门课程的资料，还原它的**设计逻辑**——先教什么、后教什么、每个环节为什么放在那里、环节之间如何衔接，交付一份自洽的《课程名》逻辑链分析报告，让学习者在深入学习前先看清全局。

## 一、创建会话

1. 打开 DSH Web 界面，新建会话；
2. 在 agent 选择处选 **课程逻辑提取器**（也可以设为默认 agent，之后新会话自动用它）；
3. 开始对话。

## 二、下达任务

一句话给出**资料位置 + 课程范围**即可，其余不用交代。**资料路径由你直接提供（任意位置、任意盘符），agent 按你给的路径读取，不预设任何固定目录**：

> 示例指令：
> - "分析 `<课程资料目录路径>` 这门课，出逻辑链报告"
> - "这是教材 PDF（`<文件路径>`）和教学大纲，帮我还原课程设计逻辑"
> - "分析这份课程资料" + 粘贴的文本

**好指令三要素**：路径给全（建议绝对路径）、说清是哪门课、可选深度档位：

| 档位 | 用途 |
| --- | --- |
| 概览 | 只读大纲/目录，快速出课程全景 + 逻辑链主线 + 模块地图 |
| 标准（默认） | 完整七节报告 |
| 深挖 | 逐小节设计意图 + 多轮自洽校验 |

不需要你交代的：不用教它怎么处理 PDF（自动走渲染+OCR）、不用指定输出格式（固定双交付物）、不用指定分析方法（技能内置）。

## 三、它会自动做什么

```
读技能 → 盘点资料（清单、形态判断、找大纲级证据）
      → 骨架提取（先目录后正文；大课程自动派子代理并行）
      → 顺序与依赖分析（为什么A在B前、暗线依赖、阶段划分、依赖图）
      → 设计意图推断（[资料明说]/[结构推断]/[推测] 三级标注）
      → 自洽性校验（反事实检验：去掉X环节会怎样）
      → 交付报告
```

期间：长任务自动用 goal 跟踪进度；PDF/图片自动跑「渲染 → DeepSeek-OCR → 合并归档 → 参考风格优化」管线（多线程、断点续跑；直出稿落盘后**自动**按内置参考产出优化稿并放进 `1-报告/`，说「只要直出稿」可跳过，说「换个参考」可换风格）；缺资料或资料明显残缺会记入「待确认」，不会编造。

## 四、交付物

**交付目录**：`课程逻辑交付/<课程名>/`（每门课一个独立文件夹，互不混淆），内部三类子目录：

```
<课程名>/
├── 1-报告/    <课程名>-逻辑链分析.md（必有）、<课程名>-学习路线图.md（默认）、<课程名>_参考风格优化版.md
├── 2-证据/    分块七要素/证据提取文件
└── 3-材料/    页面渲染/ · 逐页转录/ · 直出稿/ · 风格版分卷/
```

**主交付物必有**：`<课程名>-逻辑链分析.md`（七节报告，默认写入 `1-报告/`；你指定其他位置时以你为准）。每份报告带 YAML frontmatter（课程名/资料指纹/生成日期/深度/状态），重复分析时 agent 会对比资料指纹提示资料是否变化。

**学习路线图（默认产出）**：`<课程名>-学习路线图.md`——沿逻辑链的 3–5 阶段学习路径、验收标准、跳步警告与加速时机，与逻辑链分析同放 `1-报告/`；说「不要路线图」可跳过。

**总索引**：`课程逻辑交付/README.md` 课程总表（课程名/类型/深度/日期/状态/入口链接）随每次交付自动更新。

```
# 《课程名》逻辑链分析
1. 课程全景（定位/受众/能力终点/阶段总览）
2. 逻辑链主线（先什么、后什么、为什么，逐阶段因果句）
3. 模块地图与依赖（mermaid 图 + 暗线依赖）
4. 逐环节设计意图（定位/为什么在这里/与前后衔接/证据与等级）
5. 教学策略识别（签名 + 依据）
6. 学习路线建议（学法/验收标准/跳步警告/何时可加速）
7. 待确认清单
附录 A：资料清单   附录 B：证据索引（结论 ← 出处）
```

**材料交付物（仅当资料经过 OCR/转换时才存在）**：① **归档直出稿**（`--raw` 原样合并，页码与封面页保留）放 `3-材料/直出稿/`；② **参考风格优化稿**（直出稿落盘后**自动**产出：内容零改动、按内置《高等代数》笔记风格排版、无页码）放 `1-报告/`；逐页渲染/转录中间产物在 `3-材料/页面渲染/`、`3-材料/逐页转录/`（你指定其他目录时以你为准），随报告一并交付。若资料本身就是可直接读取的形态（`.py`/`.js` 代码、`.txt`、已有 `.md`、HTML 源码），**不发生转换，就没有材料交付物**——证据索引直接指向原始文件。

对话中会给出要点摘要（结构 + 主线 + 关键因果句），不打开文件也能先知道结论。

## 五、高级用法

- **参考风格优化版**：直出稿归档后**自动产出**，默认按内置《高等代数》笔记风格排版（开箱即用，无需配置），说「只要直出稿」可跳过本步。想换风格：说"换个参考：`路径\某笔记.md`"，agent 现场读那份笔记照着做（不改任何配置）；想永久换默认：编辑技能目录下 `reference.config.json`，或把新笔记放进 `reference\` 目录后把配置改成对应相对路径。
- **大课程并行**：几十章的大课自动按模块派子代理并行提取，主代理综合；分块证据文件自动归档到 `2-证据/`。
- **只看全局**：说"概览模式"快速出全景 + 主线，适合学前摸底。

## 六、常见问题

- **OCR 报"未找到 SiliconFlow API key"**：在 `~/.dsh/free-vision.json` 填 `{"apiKey":"sk-…"}`（硅基流动免费申请 https://cloud.siliconflow.cn），或设置环境变量 `SILICONFLOW_API_KEY`。
- **图片/扫描件/无文本层 PDF**：都能处理（自动渲染+OCR）；有文本层的 PDF 也一律走 OCR 线路，保证公式与排版正确。
- **想确认方法论**：让它"读技能"，`SKILL.md` 是唯一权威。
- **隐私**：资料仅本机处理（OCR 时图片会上传硅基流动 API，其余全本地）；报告、证据与材料 .md 都写在你自己的目录里。
- **资料是代码/文本文件**：直接分析，无需转换，也没有 `3-材料/` 产物（见「交付物」）。

一句话：**把课程资料路径丢给它，等着拿报告**——分析是它的事，你只负责给路径和看结果。
